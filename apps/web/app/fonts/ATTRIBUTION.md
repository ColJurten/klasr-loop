# Font Attribution

Klasr self-hosts these font files at build time with `next/font/local`; no runtime font CDN is used.

## Inter

- Source: Inter 4.1 release, https://github.com/rsms/inter/releases/tag/v4.1
- Files: `Inter-Regular.woff2`, `Inter-Medium.woff2`
- License: SIL Open Font License 1.1, included in `Inter-LICENSE.txt`

## JetBrains Mono

- Source: JetBrains Mono 2.304 release, https://github.com/JetBrains/JetBrainsMono/releases/tag/v2.304
- Files: `JetBrainsMono-Regular.woff2`, `JetBrainsMono-Medium.woff2`
- License: SIL Open Font License 1.1, included in `JetBrainsMono-OFL.txt`
- Authors: included in `JetBrainsMono-AUTHORS.txt`
